# Помощник Frame для YouTube

[English](README.md) · **Русский** · [Назад к Frame](../README.ru.md)

Помощник работает локально и нужен **только для YouTube**. HLS и прямые видеофайлы скачиваются без него. Требуются Python 3, yt-dlp, FFmpeg и Deno.

Используйте ID со страницы **Установить помощник** или из `chrome://extensions`. Выполняйте команду в корне проекта — папке, содержащей `native`, а не внутри `dist`.

## macOS

Установите зависимости через [Homebrew](https://brew.sh/):

```bash
brew install python yt-dlp ffmpeg deno
bash native/install-macos.sh ID_РАСШИРЕНИЯ
```

Помощник устанавливается в `~/Library/Application Support/Frame` и регистрируется в Google Chrome и Chromium для текущего пользователя, без `sudo`. При скачивании открывается системный диалог сохранения.

Обновление зависимостей: `brew upgrade yt-dlp ffmpeg deno`.

## Linux

Для Ubuntu / Debian:

```bash
sudo apt update
sudo apt install python3 pipx ffmpeg
pipx install 'yt-dlp[default]'
pipx ensurepath
```

Установите Deno по [официальной инструкции](https://docs.deno.com/runtime/getting_started/installation/). Для других дистрибутивов установите Python 3, pipx и FFmpeg своим пакетным менеджером, затем yt-dlp командой выше.

Откройте новый терминал в корне проекта:

```bash
bash native/install-linux.sh ID_РАСШИРЕНИЯ
```

Помощник устанавливается в `~/.local/share/frame`. Регистрация записывается в `~/.config/google-chrome/NativeMessagingHosts` и `~/.config/chromium/NativeMessagingHosts`. Учитываются настройки `XDG_DATA_HOME` и `XDG_CONFIG_HOME`.

Нужна обычная установка Chrome или Chromium. Браузеры из Snap / Flatpak могут блокировать помощник. Файлы сохраняются в `~/Downloads`; если имя занято, выбирается свободное. Кнопка показа файла открывает папку через `xdg-open`.

Обновление yt-dlp: `pipx upgrade yt-dlp`. Обновляйте FFmpeg и Deno способом, которым они установлены.

## Windows

Установите зависимости в PowerShell через [WinGet](https://learn.microsoft.com/windows/package-manager/winget/):

```powershell
winget install --id Python.Python.3.13 -e
winget install --id yt-dlp.yt-dlp -e
winget install --id Gyan.FFmpeg -e
winget install --id DenoLand.Deno -e
```

Откройте **новое окно PowerShell** в корне проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\native\install-windows.ps1 ID_РАСШИРЕНИЯ
```

`ExecutionPolicy Bypass` действует только для этого процесса PowerShell и не меняет постоянную политику компьютера. Сам установщик помощника не требует прав администратора.

Помощник устанавливается в `%LOCALAPPDATA%\Frame`. Регистрация Native Messaging записывается в `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.frame.downloader` и аналогичный ключ Chromium. Python запускается локальным batch-файлом.

Видео сохраняются в `Downloads` вашего профиля со свободными именами. Кнопка показа выделяет файл в Проводнике. Если Chrome был открыт во время установки зависимостей, перезапустите его. Для обновления используйте `winget upgrade --id ИМЯ_ПАКЕТА -e` с ID пакетов выше.

Установщик и код для Windows добавлены, но проверка в настоящем браузере Windows ещё не проведена.

## Проверка подключения

Вернитесь на страницу настройки и нажмите **Проверить помощник**.

| Результат | Что означает и что делать |
| --- | --- |
| **Помощник не найден.** | Помощник не зарегистрирован. Запустите установщик для своей ОС с ID расширения. |
| **Помощник не подключён к этому расширению…** | Помощник зарегистрирован, но этот ID не разрешён. Повторите установку с текущим ID. |
| **Не установлены: …** | Помощник найден, но не хватает перечисленных зависимостей. Установите их и повторите установку помощника. |
| **Помощник не запустился или отключился…** | Регистрация есть, но процесс не запустился или завершился. Проверьте Python и повторите установку. |
| **Помощник найден и готов к работе…** | Помощник ответил и нашёл зависимости. Можно попробовать скачать видео. |

Успешная проверка не гарантирует, что YouTube даст доступ к конкретному ролику. Помощник не читает cookie браузера. Требования входа, проверки «не робот», прямые эфиры и DRM не поддерживаются.

Для официального офлайн-просмотра рекомендуем [YouTube Premium](https://www.youtube.com/premium).

## Локальные данные

- `config.json` хранит разрешённые ID расширений, пути зависимостей и папку `downloadDir`. При переустановке существующие ID и выбранная папка сохраняются.
- `downloads.json` хранит до 100 путей готовых файлов для кнопки показа; `downloads.lock` координирует параллельные задания.
- Временные дорожки записываются рядом с итоговым файлом и удаляются при отмене или ошибке. На macOS существующий файл заменяется только после успешной загрузки и системного диалога сохранения. Linux и Windows не перезаписывают занятые имена.
- Команды запускаются массивами аргументов, без shell. Пользовательский конфиг yt-dlp игнорируется. Принимаются только ссылки на отдельные ролики YouTube.
- Пути зависимостей запоминаются при установке: Chrome не обязан наследовать PATH вашего терминала. После переноса зависимостей или обновления исходников помощника повторите установку.

Для удаления уберите регистрации своей ОС, указанные выше, и папку помощника Frame. Скачанные видео хранятся отдельно и останутся на месте. Расширение продолжит скачивать HLS и прямые файлы.
