Set up YouTube downloads

YouTube requires a one-time installation of frame-helper and its dependencies on your computer. HLS and direct video files work without it.

yt-dlp downloads the video, FFmpeg merges video and audio, and Deno runs the player’s JavaScript. frame-helper runs with Python 3.

1. Install dependencies

In Terminal, run the command using Homebrew:

brew install python yt-dlp ffmpeg deno

1. Install dependencies

    
For Ubuntu / Debian, run:

    
sudo apt update
sudo apt install python3 pipx ffmpeg
pipx install 'yt-dlp[default]'
pipx ensurepath

    
Install Deno using the official instructions. On other distributions, install Python 3, FFmpeg and pipx using your package manager, then install yt-dlp with the command above.
