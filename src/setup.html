Подключить скачивание YouTube

Для YouTube нужно один раз установить помощник Frame и зависимости на ваш компьютер. Для HLS и прямых видеофайлов помощник не нужен.

yt-dlp скачивает ролик, FFmpeg объединяет видео со звуком, Deno обрабатывает JavaScript плеера. Помощник запускается через Python 3.

1. Установите зависимости

В Терминале выполните команду Homebrew:

brew install python yt-dlp ffmpeg deno

2. Подключите помощник

В Терминале перейдите в папку проекта Frame — ту, в которой находится папка native, — и выполните:


    
При начале скачивания откроется диалог выбора файла. Установка помощника не требует sudo.

  

  

    
1. Установите зависимости

    
Для Ubuntu / Debian выполните:

    
sudo apt update
sudo apt install python3 pipx ffmpeg
pipx install 'yt-dlp[default]'
pipx ensurepath

    
Установите Deno по официальной инструкции. Для других дистрибутивов установите Python 3, FFmpeg и pipx через свой пакетный менеджер, затем yt-dlp командой выше.

    
2. Подключите помощник

    
Откройте новый терминал в папке проекта Frame и выполните:

    

    
Файлы сохраняются в ~/Downloads. Поддерживаются обычные установки Google Chrome и Chromium; Snap / Flatpak могут блокировать запуск помощника.

  

  

    
1. Установите зависимости

    
В PowerShell выполните команды WinGet:

    
winget install --id Python.Python.3.13 -e
winget install --id yt-dlp.yt-dlp -e
winget install --id Gyan.FFmpeg -e
winget install --id DenoLand.Deno -e

    
2. Подключите помощник

    
Откройте новое окно PowerShell в папке проекта Frame и выполните:

    

    
Помощник регистрируется для текущего пользователя. Файлы сохраняются в папку Downloads вашего профиля. Если браузер уже был открыт во время установки зависимостей, перезапустите его.

  

  

    
3. Проверьте подключение

    
После установки нажмите кнопку. Когда помощник подключится, вернитесь на страницу ролика и откройте Frame.
