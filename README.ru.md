## Зачем Frame?

Frame находит видео на текущей странице и показывает компактный список с превью, доступным качеством и размером загрузки. Видео с разных сайтов попадают в общий менеджер с отдельным прогрессом, отменой и повтором для каждого задания.

- **Выбор качества.** Доступные разрешения и запоминание предпочтения.
- **Размер до скачивания.** Точный объём, когда он известен, или явно обозначенная оценка.
- **Большие видео.** Потоковая запись HLS на диск без фиксированного лимита 450 МБ.
- **Видео со звуком.** Объединение поддерживаемых HLS-дорожек в MP4 без перекодирования.
- **Общий менеджер.** Несколько одновременных загрузок с независимой отменой.
- **Поддержка YouTube.** Дополнительный локальный помощник связывает yt-dlp с интерфейсом расширения.
- **Локальная обработка.** Без аккаунта Frame, аналитики и отправки видео на сервер обработки.

## Поддерживаемые источники

| Источник | Поддержка | Результат |
| --- | --- | --- |
| HLS VOD (`.m3u8`) | Незашифрованные TS и fragmented MP4, включая отдельный звук | MP4 |
| Прямые MP4, WebM, MOV, M4V | Доступные для скачивания ссылки на странице | Исходный формат |
| Ролики YouTube | Нужны помощник и зависимости | MP4 |
| Произвольный DASH (`.mpd`), прямые эфиры, DRM | Не поддерживаются | — |

Обнаружение ссылки не гарантирует разрешение на скачивание со стороны сервера. Некоторые плееры открывают только выбранное в самом плеере качество. Интерфейс расширения сейчас на русском языке.

## Установка

Требуются Chrome или Chromium 116+, Node.js 22+ и npm для сборки из исходников.

```bash
git clone https://github.com/lif0/frame-chromium.git
cd frame-chromium
npm ci
npm run build
```

1. Откройте `chrome://extensions` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку **`dist`** этого проекта.
3. Закрепите **Frame** на панели браузера.
4. Перезагрузите уже открытую страницу с видео и запустите воспроизведение.

Эта версия устанавливается из исходников; ссылки на пакет Chrome Web Store пока нет. После изменений исходников пересоберите расширение и нажмите кнопку обновления на его карточке.

## Использование

1. Откройте Frame на странице с видео.
2. Выберите видео, качество и нажмите **Скачать**.
3. В общем менеджере нажмите **Начать скачивание**.
4. Оставьте вкладку менеджера открытой до завершения. Popup можно закрыть.

Для HLS открывается диалог сохранения. Прямые файлы используют загрузки браузера. Для YouTube на macOS открывается диалог выбора файла, а на Linux и Windows используется папка `Downloads` пользователя. На иконке отображается количество найденных видео; при нуле счётчик скрыт.

## YouTube

**Для YouTube нужна дополнительная установка на каждом компьютере.** HLS и прямые файлы работают без помощника.

Помощник использует **Python 3**, **yt-dlp** для скачивания, **Deno** для JavaScript плеера YouTube и **FFmpeg** для объединения видео со звуком. На странице настройки есть отдельные инструкции для каждой ОС и проверка подключения.

| ОС | Инструкция | Регистрация в браузере |
| --- | --- | --- |
| macOS | [Homebrew и помощник](native/README.ru.md#macos) | Chrome / Chromium, текущий пользователь |
| Linux | [Зависимости и помощник](native/README.ru.md#linux) | Обычные установки Chrome / Chromium; Snap / Flatpak могут блокировать помощник |
| Windows | [WinGet и помощник](native/README.ru.md#windows) | Chrome / Chromium, текущий пользователь |

Откройте Frame на YouTube и нажмите **Установить помощник**. Используйте команду со страницы настройки: она содержит ID вашего расширения. После установки нажмите **Проверить помощник**.

Помощник не импортирует cookie браузера. Видео с требованием входа или проверки «не робот» могут быть недоступны. Обновляйте yt-dlp. Для официального офлайн-просмотра рекомендуем [YouTube Premium](https://www.youtube.com/premium).

## Приватность и разрешения

Настройки хранятся локально, а обнаруженные ссылки и история заданий — в текущей сессии браузера. У Frame нет серверной части и аналитики. Запросы за видео отправляются исходным поставщикам контента.

| Разрешение | Назначение |
| --- | --- |
| Доступ к HTTP/HTTPS, `webRequest` | Обнаружение и загрузка медиа |
| `scripting` | Поиск видео и превью, включая iframe |
| `storage` | Настройки и данные сессии |
| `unlimitedStorage` | Временные дорожки на диске |
| `downloads` | Сохранение прямых файлов через браузер |
| `declarativeNetRequestWithHostAccess` | Нужные заголовки доступа к медиа для запросов расширения |
| `nativeMessaging` | Связь с дополнительным локальным помощником YouTube |

Обнаруженные заголовки доступа применяются только для исходного CDN и пути. Cookie браузера не копируются. Помощник хранит локально до 100 путей готовых файлов для кнопки показа файла. Подробнее — [в инструкции помощника](native/README.ru.md#локальные-данные).

## Текущие ограничения

- Ранняя версия: совместимость зависит от сайта, а поведение YouTube может меняться.
- Для HLS нужно место под временные дорожки и итоговый MP4. Объём метаданных в памяти растёт с длительностью видео.
- Итоговый HLS-файл — fragmented MP4; старые проигрыватели могут поддерживать его не полностью.
- Не поддерживаются HLS discontinuities, смена initialization map, шифрование и DRM.
- Выбирается одна аудиодорожка по умолчанию. Выбора языка и субтитров пока нет.
- Закрытие менеджера прерывает незавершённые задания. Повтор запускает загрузку заново; продолжения с последнего байта пока нет.
- Код помощника Windows добавлен, но проверка с настоящим браузером и загрузкой на Windows ещё не проведена. Автотесты помощника используют имитацию загрузчика и не подтверждают доступность роликов YouTube.

## Разработка

```bash
npm ci
npm run check
npm test
npm run build
```

Для тестов помощника нужен Python 3. FFmpeg и ffprobe нужны для проверки сборки реального видео; без FFmpeg этот тест пропускается.

```text
src/       Интерфейс расширения, service worker, поиск и скачивание видео
native/    Помощник YouTube и установщики macOS / Linux / Windows
scripts/   Сборка и проверки
tests/     Проверки медиа, загрузок, протокола и установщиков
dist/      Собранное расширение (не хранится в Git)
```

Тесты проверяют HLS, размеры, запись на диск, сборку видео, параллельные задания, отмену, протокол помощника и регистрацию установщиков. Проверки браузера и настоящих сайтов выполняются отдельно. Для работы с браузером на другой машине см. [BROWSER-TUNNEL.md](BROWSER-TUNNEL.md).

Приветствуются сообщения об ошибках и pull requests. Указывайте ОС, версию браузера и Frame, шаги воспроизведения. Перед публикацией логов удаляйте подписанные ссылки, заголовки доступа и личные данные.

## Благодарности и лицензии

Объединение HLS выполняет [Mediabunny](https://github.com/Vanilagy/mediabunny), MPL-2.0. Его лицензия включена в сборку. Помощник использует отдельно установленные [yt-dlp](https://github.com/yt-dlp/yt-dlp), [FFmpeg](https://ffmpeg.org/) и [Deno](https://deno.com/) с их собственными лицензиями.

Лицензия для исходного кода самого Frame пока не выбрана.
